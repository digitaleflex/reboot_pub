# HashCode Creative Studio — Reboot

Chaîne de production vidéo de HashCode : **Claude Code** (orchestration), **Video Agent Skills** (vidéos sociales face caméra), **Remotion** (motion design de marque). Blender et DaVinci Resolve en option pour la 3D et la finition.

- 📋 Campagne : [`production/hashcode-reboot/`](production/hashcode-reboot/README.md)
- 🎨 Charte : [`brand/guidelines/brand.json`](brand/guidelines/brand.json)
- 🛠️ Rapport d'installation : [`docs/RAPPORT-TECHNIQUE.md`](docs/RAPPORT-TECHNIQUE.md)

## Démarrer
```bash
node .claude/skills/short-editing/engine/setup.mjs   # moteur Video Agent (une fois)
cd remotion && npm install && npm run studio         # Remotion Studio
```
Puis dans Claude Code : `/editing <ce que tu veux faire>`.
