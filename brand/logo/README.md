# Logo HashCode — fichiers officiels

**À déposer ici** (les images envoyées dans le chat ne sont pas récupérables comme fichiers) :

| Fichier attendu | Contenu | Format |
|---|---|---|
| `hashcode-horizontal.png` | Symbole H + filet vertical + « HASHCODE » | PNG transparent, ≥ 3000 px de large |
| `hashcode-stacked.png` | Symbole H au-dessus de « HASHCODE » | PNG transparent, ≥ 2000 px |
| `hashcode-symbol.svg` | Symbole H seul | SVG (idéal pour l'animation Remotion) |

Observations sur les versions reçues :
- Symbole H en deux parties obliques, vert lime avec dégradé vers un vert sombre sur la jambe droite.
- Logotype « HASHCODE » blanc, sans-serif large, avec un « A » ouvert à facette.
- La version empilée reçue a un fond blanc nuageux : il faut une version **transparente** pour la vidéo.

Le logo ne doit pas être redessiné ou approximé. Pour l'animer proprement (reveal, glow), un SVG avec le symbole et le logotype sur des calques séparés est l'idéal.
